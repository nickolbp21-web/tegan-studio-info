APPLICATION INFORMATION

Tegan Studio

Tegan Studio is a private video publishing tool for its owner. It organizes videos, prepares editable captions with AI running on the owner's computer, and publishes selected videos to connected social accounts after review.

Supported API connections include Instagram, Facebook Pages, and YouTube. Other platforms can use a manual upload workflow. The application itself requires private access; this information site does not provide sign-in or public account registration.

YouTube access

The application requests permission to upload videos and read the connected YouTube channel's profile and video metadata. It uses that access to show the selected channel and verify new uploads. It does not edit or delete existing videos.

Use is limited to accounts the owner is authorized to manage.
